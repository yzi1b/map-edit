# MapEdit

MapEdit 是一个 Paper 服务器插件：玩家在网页中上传图片、裁剪并保存为「地图画」，在游戏中获取或一键部署到墙上，自动铺满多格物品展示框。

面向 Paper 26.2（Java 25）。

## 功能

- **网页编辑器**：完整的前端裁剪/量化，图片在浏览器内转换为地图二进制后提交，服务端只做落盘。
  - 多格地图画：横 × 纵格数任意（上限取决于服务端限制），裁剪框与网格联动。
  - 量化：转换到 Minecraft 地图调色板，支持预览。
- **目录树管理**：地图画以文件夹层级组织，支持新建/删除/重命名路径式访问，指令带 Tab 补全。
- **获取地图**：`/mapedit give <路径>` 一次拿到整幅地图画的所有地图。
- **一键部署**：`/mapedit deploy <路径>` 获得「起始地图」，放进左上角展示框后其余地图自动铺好——墙面、地板、天花板均可，朝向自动校准，失败整体回滚。
- **替换与导出**：网页中可用新图替换已有地图画（尺寸不变），也可导出整幅 PNG。
- **部署偏好**：`/mapedit prefer` 控制展示框类型（荧光/隐形/跟随/强制替换），`/mapedit check` 控制部署前检查。

## 环境要求

| 项 | 版本 |
|---|---|
| 服务器 | Paper 26.2（build 121 实测） |
| Java | 25 |
| Gradle | 随 wrapper（9.7.0） |

## 构建

```bash
./gradlew build          # Windows: gradlew.bat build
```

产物：`build/libs/MapEdit-1.0.0.jar`，放入服务器 `plugins/` 目录。

## 快速开始（本地测试服）

```bash
./gradlew runServer      # 一键起一个带插件的 Paper 测试服，数据目录 run/
```

或使用仓库内 `.run/MapEditServer.run.xml`（IDEA 运行配置）。

进服后：

1. `/mapedit web` — 聊天栏会收到一条可点击的链接，用浏览器打开。
2. 在网页中新建文件夹/上传图片，调整裁剪与网格，保存。
3. `/mapedit deploy <路径>` — 拿着发到的地图对准左上角展示框右键，自动铺满。
4. 也可 `/mapedit give <路径>` 先拿到全部地图手动摆放。

测试服 RCON 驱动（可选）：

```bash
python scripts/rcon.py "mapedit web"
# 连接参数可用环境变量覆盖：MAPEDIT_RCON_HOST / MAPEDIT_RCON_PORT / MAPEDIT_RCON_PASSWD
```

## 指令与权限

| 指令 | 权限节点（默认 op） | 说明 |
|---|---|---|
| `/mapedit web` | `mapedit.web` | 生成临时 Web 访问链接（私发，含 token） |
| `/mapedit give <路径>` | `mapedit.give` | 按行优先给予整幅地图画的地图 |
| `/mapedit deploy <路径>` | `mapedit.deploy` | 发放「起始地图」用于展示框部署 |
| `/mapedit prefer [属性 值]...` | `mapedit.prefer` | 部署偏好：`glow` / `invisible` / `reference` / `force` |
| `/mapedit check true\|false` | `mapedit.prefer` | 部署前附着/占位检查开关 |

路径不带先导 `/`，目录以 `/` 结尾；Tab 补全可用。无权限玩家既不能用指令，也不能使用已发放的部署道具。

## 配置

`plugins/MapEdit/config.yml`：

```yaml
web:
  port: 35565                 # 监听端口
  uri: "http://localhost:35565/"   # 对外 URI，仅用于游戏内拼接链接（可配域名/反代）
  bind: 127.0.0.1             # 监听地址；0.0.0.0 监听所有网卡
  token-ttl-seconds: 600      # token 有效期；页面活跃时心跳续期
```

Web 服务默认只监听本机回环地址。如需公网访问，请自行配置反向代理与 HTTPS，并评估安全风险（见下文「已知限制」）。

## 工作原理（简述）

- 地图画元数据存于**存档目录**（`<level>/mapedit/tree.json`），像素数据存 `mapedit/pixels/<pid>.bin`（gzip）。
- 地图数据由插件**直接写地图 NBT 文件**：自分配一个高位地图 ID 区（≥ 10 亿）以避免与服务器原有地图编号冲突。
- 网页端即完成量化与切片，服务端只接收最终地图颜色数组并落盘，重启不丢。
- 部署时按玩家视角与展示框朝向计算行列方向，自动补齐缺失展示框；单面失败整体回滚。

> 地图画按「存档（level）」隔离：同一存档跨维度通用，不同存档之间不可互用。

## 已知限制与安全提示

- **插件尚在早期阶段**，完整的安全审计与大规模生产环境验证尚未完成，请勿直接用于无备份的重要服务器。
- 地图 ID 自分配高位区：与极少数同样自分配地图 ID 的插件/工具**可能冲突**，部署前请在测试服验证。
- 上传接口目前未限制请求体大小与图片解码尺寸，大图/恶意请求可能造成内存压力（加固进行中）。
- 网页服务默认本机监听；若改为公网监听，需自行加上 TLS、限流与访问控制。调试端点 `/dev/tree` 仅限本机诊断，上生产前请自行移除或限制。
- 大尺寸地图画的网页预览渲染为同步循环，接近上限格数时会卡顿数秒。
