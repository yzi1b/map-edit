# 地图编辑器插件

cn.lyricraft.mapedit

## 用途

用于编辑地图画。将玩家上传图片作为一个地图画，转为一个或多个锁定地图存储。同时保留数据文件，用以记录地图画元数据，以及其与相关地图文件的对应关系。地图画模拟目录树结构存储。可指定文件名（可用中英及有效符号）。

### Web

可设置端口（默认35565）、URI（默认http://localhost:35565/，只用于在游戏内拼接URL便于玩家打开）、监听IP（默认127.0.0.1，可设为0.0.0.0来监听所有）。

Web页面需要临时token来访问和操作，该token在游戏中酌权限生成。

Web界面有目录树，可以新建、删除文件夹，新建、删除地图画。新建地图画，玩家上传图片，可以裁剪，可以设置横纵地图个数（这也决定裁剪比例）。设置好文件名（同目录不可重名）。网页中即用脚本将地图画转换成对应的地图二进制，传给服务端。服务端按现状分配地图编号，写入锁定地图数据，写入元数据。不仅可以新建地图画，还可以用新图片替换，但横纵地图数量不能变。

可以查看相关地图画，可以快速复制相关地图画获取和部署指令。

### 指令

/mapedit ...

所有指令有相应权限节点，管理员可用。

地图画路径应当有相关缺省提示（候选Tab表）。

#### 打开Web

/mapedit web

若有权限，则生成临时token，与URI拼接后私发给该玩家，便于其打开和访问Web页面。

#### 获取地图画的地图

/mapedit give 地图画路径

按顺序给予该地图画的全部地图。

#### 部署地图画

/mapedit deploy 地图画路径

给予玩家一个道具，为一个填充地图，id为指定地图画最左上角的一块。描述中说明地图画横纵数量几乘几，引导玩家置于左上角以部署。该道具有特殊NBT，便于插件监测放置行为来执行部署行为。

玩家将此道具放在物品展示框上时，相对玩家视角，将此展示框视为地图画左上角，自动填充其余地图片。要求必须有足够大的可依附平面。如果平面某一地图位置有物品展示框，则直接安置。如果没有，则自动安置物品展示框或荧光物品展示框，具体哪一个以玩家实际交互到的（左上）为准。注意兼容物品展示框在方块上下左右前后的情况，地图角度也要调整好。

没有权限的玩家不仅不能使用此命令，也不能使用此道具部署。

如果由于某些原因未部署成功，则回撤更改，并用红字私发警告消息。
